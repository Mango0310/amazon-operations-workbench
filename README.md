# 亚马逊运营分析与独立操盘成长工作台

针对**亚马逊运营管培生**岗位的求职项目，模拟从基础运营执行、数据分析到独立操盘的完整工作流程。

通过销售、订单、产品、Listing、广告、库存、竞品、利润等数据，完成 **经营目标 → 数据整理 → 经营分析 → 异常发现 → 运营动作 → 复盘验证** 的闭环。

## 核心定位

一句话："这个项目不是单纯把亚马逊数据做成报表，而是建立一个从数据整理、数据分析、异常发现，到运营动作的闭环。"

## 功能模块

| 模块 | 说明 |
|---|---|
| **经营驾驶舱** | 近 7 天目标达成、销售与广告趋势、SKU 贡献和今日优先事项 |
| **SKU 经营诊断** | 围绕单个 SKU 查看销售、流量、转化、广告、库存、利润、竞品，并可生成 AI 复盘草稿 |
| **广告与利润** | 分析 ACOS、TACOS 与经营利润，并把搜索词分成精准扩量、降价、否定/暂停和观察 |
| **库存管理** | 计算可售天数、预计断货日、补货量与到仓判断 |
| **Listing** | 用问题总览和单个 SKU 逐项解释完成基础预检 |
| **行动与复盘** | 将异常转为动作，并记录执行前后指标、结果判断、复盘结论和下一步 |
| **数据中心** | 分批导入、字段识别、基础校验、增量合并、完整度与跨表 SKU 检查 |

## 数据设计

20 个 SKU × 30 天，故意设计不同业务情况：

高销量 3 / 普通 7 / 新品 3 / 高 ACOS 2 / 库存预警 2 / 销量下降 2 / 高毛利 1

8 张数据表（CSV，可用 Excel 打开）：

产品表、Listing、销售表、库存表、广告表、搜索词表、竞品表、利润表

## 真实数据接入

不需要先手工整理完所有数据再一次性上传。“数据中心”支持按表识别、字段映射、校验与增量合并：

- **销售表**：从 Amazon Business Reports 导出，按“日期 + SKU”追加；重复日期和 SKU 时以本次导入为准。
- **广告表**：从 Sponsored Products 报告导出，同样按“日期 + SKU”追加。
- **搜索词表**：从搜索词报告导出，按“SKU + 广告活动 + 搜索词”更新，用于关键词动作诊断。
- **库存表**：从库存报告导出，作为最新库存快照覆盖更新。
- **产品表、Listing**：低频维护，按 SKU 用最新资料覆盖。
- **竞品表**：示例数据由程序模拟；真实使用应标注竞品 ASIN、人工/工具来源和采集日期。
- **利润表**：由销售、采购成本、FBA/平台费用、广告费与退款汇总，建议每周或每月更新。

当前版本是本地 CSV/Excel 工作流：适合小团队手动运营。真实工作环境可在此导入层外增加 Amazon SP-API、广告 API 或 ERP 数据仓库同步，但应先完成账号授权、数据权限和口径校验。

数据中心还提供一份公式驱动、已做视觉校验的示例 Excel 周报，可用于演示经营概览、SKU 利润、搜索词诊断和行动复盘。它使用模拟数据，不代表真实店铺成绩。

## 技术栈

Excel/CSV + Pandas + Streamlit。核心指标计算全部本地完成；AI 仅用于生成复盘初稿，规则诊断在没有 AI 时仍可独立运行。

## AI 接入

项目通过独立的 `src/ai_provider.py` 适配层接入 AI，经营页面不与某一家模型服务绑定：

- **本地 Ollama**：模型在本机运行，不需要 API Key。工作台会自动读取已经安装的模型。
- **自定义云端接口**：支持使用 Chat Completions 请求和响应格式的其他模型服务，需要填写完整接口地址、模型 ID 和 API Key。

AI 输入仅包含当前 SKU 的汇总指标、系统风险和竞品摘要；输出包括经营摘要、待验证假设、最多三个优先动作、验证指标、复盘时间和风险提醒。API Key 只保存在当前 Streamlit 会话，不写入项目文件。

新增其他 AI 提供方时，只需在 `src/ai_provider.py` 的 `generate_review` 中增加适配分支，不需要修改 SKU 诊断页面。

## 项目使用说明

数据为模拟数据，不应包装为真实店铺业绩。

```
├── app.py               # Streamlit 入口（7 个经营视图）
├── generate_data.py     # 模拟数据生成
├── data/                # 8 张数据表 CSV
├── outputs/             # 示例 Excel 经营周报
├── src/
│   ├── schema.py        # 字段规范 + 映射
│   ├── importer.py      # 数据导入 + 校验
│   ├── analytics.py     # 指标计算引擎
│   ├── rules.py         # 异常规则引擎
│   └── ai_provider.py   # 本地/云端 AI 提供方适配层
└── scripts/             # 周报生成等脚本
```
